# Waymate


Waymate is a mobile app that pairs you with someone chasing the same goal, then helps the two of you plan it, check in, and keep going until it's done.

It's in development and being built in public, starting with people studying for the CFA exam.

This repo is the landing site at [waymate.app](https://waymate.app), built with Vite, React, and Tailwind.

Follow the build on LinkedIn and X, or visit [armineslamieh.com](https://armineslamieh.com).
